# OVYON OS Frontend

This is the repository for the official [OVYON OS](https://ovyon.io) frontend.

[![Screenshot of the frontend](https://raw.githubusercontent.com/ovyon/frontend/master/docs/screenshot.png)](https://demo.ovyon.io/)

- [View demo of OVYON OS](https://demo.ovyon.io/)
- [More information about OVYON OS](https://ovyon.io)
- [Frontend development instructions](https://developers.ovyon.io/docs/frontend/development/)

## Development

- Initial setup: `script/setup`
- Development: [Instructions](https://developers.ovyon.io/docs/frontend/development/)
- Production build: `script/build_frontend`
- Gallery: `cd gallery && script/develop_gallery`

## Frontend development

### Classic environment

A complete guide can be found at the following [link](https://www.ovyon.io/developers/frontend/). It describes a short guide for the build of project.
